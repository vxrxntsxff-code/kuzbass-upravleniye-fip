## 📌 Ключевые возможности платформы

1. **Комплексная стандартизированная диагностика дефицитов:**
   * Интерактивный лист самооценки по 5 группам управленческих компетенций (шкала 0–4).
   * Комплексный тест на 20 заданий с автоматической проверкой и подробными нормативными обоснованиями (ссылки на ФЗ № 273-ФЗ, 44-ФЗ, 223-ФЗ, 152-ФЗ, ТК РФ, ГК РФ, БК РФ, Приказ Минтруда № 250н, ФГОС и ФОП актуальности 2026 года).
   * 4-уровневая шкала дефицитов (низкий, выше среднего, средний, высокий).
2. **Индивидуальная образовательная траектория (ИПР):**
   * Автоматическая генерация задач и модулей развития на основе выявленных дефицитов.
   * Управление статусом освоения («Запланировано» → «В процессе» → «Освоено»).
   * Прикрепление наставника из региональной Лиги экспертов.
3. **Электронное аттестационное портфолио:**
   * 6 официальных разделов управленческих доказательств.
   * Загрузка документов (PDF, DOCX, XLSX).
   * Статусы верификации («На проверке», «Одобрено комиссией», «На доработке»).
4. **«Эффективный диалог» (вопрос-ответ):**
   * Прямая линия консультаций руководителей с Лигой экспертов и наставников.
   * Публикация официальных ответов на управленческие вызовы.
5. **Кадровый резерв «КУЗБАСС.БУДУЩЕЕ.РФ»:**
   * Трёхуровневая модель работы с кадровым резервом.
   * Банк инициатив и проектов с открытым региональным голосованием.
6. **Библиотека руководителя:**
   * 4 раздела нормативно-правовой базы с прямыми ссылками на первоисточники.
   * Методические материалы и банк из 200+ реальных кейсов и симуляций.

## 💻 Локальный запуск (для разработчика и тестирования)

Требования: Node.js версии 20+ (включая встроенный модуль `node:sqlite`).

```bash
# 1. Установка зависимостей
npm install

# 2. Запуск сервера
npm start

# Приложение будет доступно по адресу:
# http://localhost:3000
```

Для режима разработки с автоперезапуском при изменении файлов:
```bash
npm run dev
```

## 🚀 Инструкция для системного администратора (развертывание на сервере)

### Вариант 1: Запуск через Docker & Docker Compose (рекомендуемый)

На целевом Linux-сервере:
```bash
# Клонирование репозитория
git clone <url-репозитория> kuzbass-platform
cd kuzbass-platform

# Запуск контейнера в фоновом режиме
docker-compose up -d --build

# Проверка статуса
docker-compose ps
docker-compose logs -f
```

База данных SQLite (`./data/kuzbass_edu.db`) и загруженные файлы (`./uploads`) монтируются через volumes и сохраняются при перезапусках контейнера.

---

### Вариант 2: Запуск через PM2 и Nginx (на сервере с Node.js)

1. Установите PM2 глобально:
```bash
npm install -g pm2
```

2. Запустите процесс через PM2:
```bash
pm2 start server/index.js --name "kuzbass-edu-platform"
pm2 save
pm2 startup
```

3. Пример конфигурации Nginx (`/etc/nginx/sites-available/kuzbass-edu.conf`):
```nginx
server {
    listen 80;
    server_name education.kuz-edu.ru; # или IP-адрес сервера

    client_max_body_size 30M;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
    }
}
```

Активация и перезагрузка Nginx:
```bash
sudo ln -s /etc/nginx/sites-available/kuzbass-edu.conf /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```
